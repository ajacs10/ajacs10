# 📊 WORKEANLY

### Labour Market Analytics

**WORKEANLY** é um projecto de análise de dados orientado para o estudo do **mercado de trabalho e da procura por competências profissionais**.

O projecto utiliza um conjunto de dados estruturado de ofertas de emprego, empresas, competências, países e plataformas, permitindo analisar diferentes dimensões do mercado de trabalho.

### 🎯 Objectivos

O projecto procura responder a questões como:

- Quais são as competências mais procuradas?
- Quais são as profissões com maior procura?
- Que empresas apresentam maior actividade de contratação?
- Quais são as localizações com maior concentração de oportunidades?
- Que competências aparecem associadas a determinadas profissões?
- Como se distribuem os diferentes tipos de emprego?
- Que padrões podem ser identificados nos dados?
- Que indicadores podem apoiar decisões relacionadas com o mercado de trabalho?

### 🔄 Pipeline de Dados

```text
Raw Data
    ↓
Python
    ↓
Polars
    ↓
Data Cleaning
    ↓
Data Transformation
    ↓
Microsoft SQL Server
    ↓
SQL Analysis
    ↓
Business Insights
````

### 📁 Estrutura dos Dados

O projecto trabalha com diferentes dimensões de informação:

```text
Job Postings
    │
    ├── Companies
    ├── Countries
    ├── Platforms
    └── Skills
             │
             └── Job ↔ Skill relationship
```

A estrutura do dataset inclui uma tabela principal de ofertas de emprego, dimensões de empresas, países, plataformas e competências, além de uma tabela de relacionamento entre ofertas e competências.
